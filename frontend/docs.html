Snyf API Reference

Use these endpoints to create accounts, manage API keys, upload catalogs, poll ingestion jobs, and search enriched collections.

https://xydj4rm9eg.execute-api.us-east-1.amazonaws.com

Authentication

Signup and login use email/password. Catalog upload, job polling, and search use the customer API key in the x-api-key header.

POST

/auth/signup

curl -sS -X POST "$API_URL/auth/signup" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "customer@example.com",
    "password": "password123"
  }'

Returns customer, session, refresh_token, api_key, and api_key_id.

POST

/auth/login

curl -sS -X POST "$API_URL/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "customer@example.com",
    "password": "password123"
  }'

Returns customer, session, and refresh_token.

API Keys

Use the login refresh_token as a bearer token for API-key management.

GET

/auth/api-keys

curl -sS "$API_URL/auth/api-keys" \
  -H "Authorization: Bearer $REFRESH_TOKEN"
POST

/auth/api-keys

curl -sS -X POST "$API_URL/auth/api-keys" \
  -H "Authorization: Bearer $REFRESH_TOKEN"
POST

/collections/{collection_id}/upload

Uploads a catalog CSV to one collection and queues accepted rows for enrichment.

curl -sS -X POST "$API_URL/collections/coll_ss25/upload" \
  -H "x-api-key: $API_KEY" \
  -F "csv_file=@catalog.csv" \
  -F "attribute_list_id=fashion-v1" \
  -F "process_now=false"
InputRequiredNotes
csv_fileYesCSV file with product rows.
attribute_list_idYesAttribute-list file name, not an S3 URI.
process_nowNoUse false for queued production ingestion.

Required CSV columns: product_id, name, image_urls. Optional columns: collection_id, category, description, price, currency, brand, attributes, _deleted.

/ingestion-jobs/{job_id}

/search

Searches one collection and returns ranked product results with image URLs.

curl -sS -X POST "$API_URL/search" \
  -H "Content-Type: application/json" \
  -H "x-api-key: $API_KEY" \
  -d '{
    "collection_id": "coll_ss25",
    "query": "flowy beach wedding look",
    "top_k": 5
  }'
FieldRequiredNotes
collection_idYesMust belong to the API-key customer.
queryYesNatural-language product search.
top_kNoDefaults to 20. Maximum is 100.
